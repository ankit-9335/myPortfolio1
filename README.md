# Ankit Singh — Developer Portfolio

A modern, single-page developer portfolio built with **HTML, CSS, and JavaScript**, designed with a developer/editor-inspired interface.

The portfolio showcases my **technical skills, experience, projects, education, certifications, and contact information** with interactive UI elements such as dark/light mode, animated counters, scroll reveals, terminal-style effects, and a 3D developer workspace.

## ✨ Features

* 🖥️ Developer/editor-inspired UI
* 🌙 Dark & light theme
* ⌨️ Terminal-style typing animation
* 📊 Animated portfolio statistics
* 📈 Skill proficiency indicators
* 🔀 Section filtering
* 📜 Git-log-inspired experience timeline
* 🎨 Interactive hover and scroll animations
* 🧊 3D developer workspace using Three.js
* 📄 Downloadable résumé
* 🔗 LinkedIn, GitHub & LeetCode links
* 📱 Responsive design for different screen sizes

## 🛠️ Tech Stack

| Technology   | Purpose                                       |

## 🚀 Run Locally

This project does not require a build tool or package installation.

### Option 1 — Open directly

Simply open:

```text
index.html
```

in your browser.

### Option 2 — Run with a local server

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## 🌐 Deploy with GitHub Pages

1. Create a GitHub repository named `portfolio`.
2. Push all project files to the `main` branch.
3. Open the repository on GitHub.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select:

   * **Source:** Deploy from a branch
   * **Branch:** `main`
   * **Folder:** `/ (root)`
6. Click **Save**.

The portfolio will then be available at:

```text
https://ankit-9335.github.io/portfolio/
```

## 📌 Important

Make sure `final_resume.pdf` is present in the project root:

```text
portfolio/
├── index.html
├── style.css
├── script.js
├── final_resume.pdf
└── README.md
```

The résumé buttons in the portfolio reference this file directly.
